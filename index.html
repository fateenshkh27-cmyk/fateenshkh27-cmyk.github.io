Smart EV Charging Kiosk

Engineering Project Portfolio

Project Overview

Development of a Smart EV Charging Kiosk using Raspberry Pi and a touchscreen interface. The system is designed to provide an interactive charging interface and display charging parameters.

Hardware and Technologies

  • Raspberry Pi 4B
  • Python and Tkinter GUI
  • 5.5-inch touchscreen
  • RFID module
  • ACS712 current sensor
  • Relay module

Key Features

  • Charging start and stop interface
  • Voltage and current monitoring
  • Power and energy consumption display
  • Charging session time tracking

About the Project

This project explores embedded systems, user-interface development, sensor integration, and smart charging control.
